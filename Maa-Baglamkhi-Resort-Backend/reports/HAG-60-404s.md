## Busboy 1.6.0 bug (found while verifying, not caused by my code)

All multipart POST/PUT on the accounts routes return **500 `Unexpected end of form`** on the live server — including routes I never touched (e.g. `POST /api/accounts/bank-ledger`). Root cause: `node_modules/busboy@1.6.0` is broken on node 20.20.0 (reproduced in a clean directory: `npm i busboy@1.6.0`, one minimal multipart body → same error). It is a known upstream defect; the fix is to bump busboy (or multer's transitive busboy) to a patched build. **No published busboy fix exists on npm yet** (I tried 1.7.0 — not published). The multipart parser itself (`memoryStorage.none()`) is correct code; it just can't complete because busboy throws on `_final`. This blocks the payment-settings form end-to-end until busboy is patched. Flag for a separate ticket.
